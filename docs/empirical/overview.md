# Empirical Grounding — Overview

This section documents the model's *provenance*: which narrative claims from Game Theory #21 are measurable, which are contradicted by data, and which remain speculative.

## Methodology

1. **Identify claim** — extract a testable statement from `game-theory-21.txt`.
2. **Find official source** — EIA, IEA, CSIS, RAND, ANRPC, DoD, Energy Institute, etc.
3. **Compare** — model-parameter range vs. official data range.
4. **Classify** — Confirmed / Partially Supported / Rejected.

## Taxonomy

| Status | Icon | Definition |
|--------|------|------------|
| **Confirmed** | `!!! success` | Claim matches official data within model uncertainty bounds. |
| **Partially Supported** | `!!! warning` | Some evidence exists, but critical elements remain unverified or evolving. |
| **Rejected / Unverified** | `!!! failure` | Claim contradicts official data or lacks any verifiable source. |
